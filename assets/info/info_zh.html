XYrminal — 用户指南

XYrminal 是一款多协议终端，用于通过串口、TCP 和 UDP 与设备通信。 它可以作为客户端或服务器运行，传输文件，绘制实时图表，执行宏和场景 脚本，用触发器高亮子字符串，并将一切保存到磁盘。

1. 标签页概览

  • COM — 串口（RS-232、RS-485、USB-CDC）。
  • TCP Client — 连接到远程 TCP 服务器。
  • TCP Server — 监听本地端口，接受多个客户端。
  • UDP Client — 与固定的 host:port 通信。
  • UDP Server — 绑定本地端口，接收任意来源，支持广播。

2. COM 标签页

2.1 连接

  • 在下拉列表中选择端口；如果列表过时，请按 扫描。
  • 连接 打开端口，断开 关闭端口。
  • 端口打开时：
    • DTR 和 RTS 拨动开关控制两条输出线。DTR 通常 接到 MCU 复位引脚；RTS 接到 BOOT0 或 bootloader 使能引脚。 点击它们可以在不重新打开端口的情况下翻转线路。
    • 四个 LED 显示输入线：CD、RI、DSR、 CTS。绿色 = 线路有效，暗色 = 无效。

2.2 串口设置

波特率、数据位、校验位、停止位、流控制。每个下拉列表底部都有一个 自定义… 条目，用于非标准值。

2.3 终端设置

  • 自动滚动 — 新数据到达时跳到末尾。
  • 时间戳 — 每行前面加上 [HH:MM:SS.mmm] 前缀。
  • 自动保存日志 — 当前会话在运行时直接写入文件。
  • 格式 — 如何解码传入字节：
    • 原始：HEX、DEC、OCT、BIN。
    • 文本：ASCII、UTF-8、UTF-16 LE、 UTF-16 BE、CP1251、CP1252、CP866、 KOI8-R、Latin-1、Shift-JIS、GB2312、 GBK。
    在原始模式下，每个接收到的块立即作为单独一行打印。在文本模式下， 部分行会被缓存，直到换行符到达 或 经过 50 毫秒的静默 — 没有末尾换行符的数据仍会显示（Hercules 风格 flush）。
  • 图表 — 打开实时图表面板（见第 5 节）。
  • 清空 — 清空终端视图。
  • 保存日志 — 将当前缓冲区保存到 logs/。

2.4 发送

  • 输入文本，按 Enter 或 发送。↑ / ↓ 浏览输入历史。
  • HEX — 将输入视为十六进制字节（"AA BB CC" → 3 字节）。 在 HEX 模式下 +CR 和 CR=CR+LF 被忽略。
  • +CR — 追加行结束符。使用 CR=CR+LF 时变为 CR+LF，否则仅为 CR。
  • 宏 — 见第 7 节。
  • 文件传输 — 见第 6 节。

3. TCP / UDP 客户端标签页

  • 连接 — 远程主机 / 端口、可选的本地绑定、超时。
  • 保持连接（仅 TCP Client）— 如果对端断开，工作线程每 2 秒 重试一次，直到重新连接或按断开。
  • Ping — TCP connect() 探测，统计信息与 PowerShell 的 Test-Connection 相同：检查运行固定序列，开始运行 周期性 ping，停止结束它。

4. TCP / UDP 服务器标签页

  • TCP Server — 监听、客户端列表、可选的 回显、 可选的 广播给所有、断开单个或所有对端。
  • UDP Server — 绑定、接收任意来源、记住最后发送者、 回复给最后发送者 / 明确地址 / 广播到 255.255.255.255。
  • 传入数据以 [host:port] 为前缀。服务器事件 （[+]、[-]、监听、停止）使用专用颜色。

5. 实时图表

在“终端设置”中按 图表。终端区域分成两半：左边文本，右边 实时图表。

  • 每行 = 一个变量：名称 + 解析标记。名称必填； 标记可选。
    • 有标记（例如 VREF=）：解析器在传入文本中查找 标记，读取其后的第一个数字。
    • 无标记：解析器读取传入块中任意位置的第一个数字。
  • 多行 = 同一图表上的多条曲线，每条都有自己的颜色。
  • 开始 开始采集。暂停 / 继续 冻结采集而不丢失数据。 停止 结束会话并关闭面板。
  • T-Mode — X 轴变为 秒数之前 而不是采样索引。即使 没有新数据，图表也持续滚动。
  • View — 窗口中显示多少点（索引模式）或秒数（T-Mode）。
  • Export CSV — 将所有捕获的通道保存为适合电子表格的 CSV 文件：index,time_s,<通道1>,<通道2>,…。 缺失的尾部值留为空白单元格。UTF-8 带 BOM，让 Excel 正确打开 西里尔字母通道名称。
  • 将鼠标悬停在图表上以查看带有确切值的工具提示。

6. 文件传输

  • 在 COM、TCP Client 和 UDP Client 标签页中可用。
  • 协议：
    • Raw — 以原始字节块发送文件，块间延迟可配置。 适合 bootloader、镜像、配置。
    • XMODEM — 经典 128 字节块，CRC-16，ACK/NAK 握手， 每块最多重试 10 次。
    • YMODEM — XMODEM-1K，第一个块为文件名/大小。STM32 / ESP / AVR bootloader 的标准。
    • ZMODEM — 尚未实现。
  • 块大小、块延迟和最大文件大小在 设置 → 传输设置 中配置。在那里还可以启用 记住最后发送的文件路径，以便在下次启动时恢复路径和 协议。
  • XMODEM / YMODEM / ZMODEM 不支持通过 UDP。

7. 宏和场景

每个标签页有 10 个槽位 M1…M10。每个槽位可以存放普通宏或场景脚本。

7.1 普通宏

  • 短文本（或十六进制字节），一键发送。
  • 每个宏有自己的 +CR、CR=CR+LF 和 HEX 标志 — 与输入字段上方的标志无关。
  • 将鼠标悬停在按钮上可以看到内容。空槽位禁用。

7.2 场景脚本 (.xyscen)

一个简单的 UTF-8 文本文件，每行一个命令。命令有两种风格， 可以在同一文件中自由混合：

风格 A — 扁平式，每行一个命令（原始语法，完全支持）：

# 注释
// 也是注释
send "AT+RST\r\n"
send HEX "AA 55 01 FF"
wait 3000
expect "OK" 2000
expect_search "ERROR" 3000
assert_rx "READY"
log "你好"
let x = 5
send "AT+SET=$x\r\n"

风格 B — 类 C 块的迷你语言（变量、表达式、if/else、 while、for）：

let id = 3
let ok = 0

for (let i = 0; i < id; i++) {
    send "AT+PING\r\n"
    if (expect("PONG", 2000)) {
        ok++
    } else {
        log "设备 $i 未响应"
    }
    wait 200
}

if (ok == id) {
    log "所有 $id 通过"
} else {
    log "$ok / $id 通过"
}

两种风格可以混用。用原始语法写的旧脚本继续正常工作。

7.3 命令完整参考

发送数据

  • send "文本" — 发送字符串 (UTF-8)。转义： \r \n \t \\ \" \' \0 \xNN。
  • send HEX "AA 55 01 FF" — 旧别名，发送原始十六进制 字节。
  • send[ENC] "文本" — 与 send 相同，但 使用显式编码。支持的 ENC：
    • 原始：HEX ("AA 55")、BIN ("10101010 01010101")、 DEC ("170 85")、OCT ("252 125")。
    • 文本：UTF-8、ASCII、UTF-16LE、 UTF-16BE、CP1251、CP1252、CP866、 KOI8-R、Latin-1、Shift-JIS、GB2312、 GBK。
  • send_slow[ENC] "文本" ms — 逐字节发送，字节间延迟 ms 毫秒。用于慢速 MCU 串口。无 [ENC] 时 使用 UTF-8。

等待和检查

  • wait ms — 暂停指定毫秒数。
  • expect "文本" ms — 最多等待 ms 毫秒，直到 RX 中出现 文本。只考虑调用之后接收到的字节。 超时则脚本失败。
  • expect_search "文本" ms — 同上，但搜索整个 RX 缓冲区（自脚本启动以来累积）。当设备在开始等待之前 就已发送了文本时很有用。
  • assert_rx "文本" — 检查 文本 是否已经 在 RX 缓冲区中。立即，不等待。
  • 在表达式形式（风格 B）中，expect(...)、 expect_search(...) 和 assert_rx(...) 返回布尔值，失败时不会终止脚本。适合放在 if (...) 中。

变量和输出

  • let 名称 = 值 — 定义变量。值可以是数字、带引号的 字符串，或 $另一（引用）。
  • 在任何字符串中，$名称 会插入变量的值： send "AT+SET=$id\r\n"。
  • log "文本" — 作为 [SCENARIO] 文本 打印到终端。支持 $var 插值。
  • print 表达式 — 打印任意表达式的值。

控制结构（风格 B）

  • if (条件) { ... } else if (条件) { ... } else { ... }。
  • while (条件) { ... }。
  • for (初始化; 条件; 步进) { ... }。
  • 循环中的 break / continue。

运算符（风格 B）

  • 算术：+ - * / %。
  • 比较：== != < > <= >=。
  • 逻辑：&& || !（短路）。
  • 自增 / 自减：x++、x--。
  • 复合赋值：+= -= *= /= %=。

内置函数

expect("needle", ms) bool — 见上。
expect_search("needle", ms) bool — 见上。
assert_rx("needle") bool — 立即检查整个 RX 缓冲区。
num_from_rx(marker) int — RX 缓冲区中 marker 之后的第一个数字。空 marker → 整个缓冲区中的第一个数字。未找到返回 0。 小数部分截断（仅整数）。
len(s) int — 字符串长度。
num(s) int — 解析数字；非数字返回 0。
str(v) 字符串 — 转换为文本。
abs(n) int — 绝对值。
time_ms() int — 自脚本开始以来的毫秒数。

7.4 实际示例

# 读取温度并切换风扇
send "AT+READ\r\n"

if (expect("OK", 2000)) {
    let t = num_from_rx("TEMP=")
    log "温度 = $t"
    if (t > 30) {
        send "AT+FAN=1\r\n"
    } else {
        send "AT+FAN=0\r\n"
    }
} else {
    log "设备未响应"
}

7.5 配置槽位

  • 设置 → 配置宏 → <标签页> 打开一个包含 10 行的对话框。 每行：文本字段 + +CR + CR=CR+LF + HEX。
  • 顶部按钮：
    • 添加场景… — 选择一个 .xyscen 文件和一个 槽位号。槽位的按钮变为 S#。
    • 清除场景 — 将槽位恢复为普通宏。
  • 设置 → 重置所有宏 → … 清除一个标签页或所有标签页的宏。
  • 场景运行时，所有宏和输入行都被禁用。进度以 [SCENARIO] … 行使用自己的颜色打印。

8. 触发器

每个标签页可以用自定义前景色和背景色高亮终端输出中的子字符串。

  • 设置 → 配置触发器 → <标签页> 打开一个对话框。
  • 每行：要匹配的文本 + 前景色样本 + 背景色样本。
  • 匹配不区分大小写；重叠时靠上的行优先。
  • 每个标签页最多 50 个触发器。
  • 触发器也会保存在 .xyrmc 日志中，浏览器会渲染相同的 高亮。
  • 设置 → 重置触发器 → <标签页> / 全部 清除它们。

9. 日志

  • 保存日志 — 将当前缓冲区写入应用旁边的 logs/， 自动生成文件名。
  • 日志另存为… — 选择路径和格式：
    • .xyrm — 纯 UTF-8 文本。
    • .xyrmc — 带内联颜色的完整 HTML 文档。在任何浏览器中 打开，可以看到终端当时的精确状态，包括触发器高亮。
  • 打开日志… — 打开以前保存的日志：
    • .xyrm — 加载到当前标签页的终端中。
    • .xyrmc — 打开一个单独的查看器窗口，带有 播放 / 暂停 / 停止 工具栏，按原始行间延迟重放日志。
  • 打开日志文件夹 — 在文件管理器中打开 logs/。

10. 设置菜单

主题 10 种内置调色板、跟随操作系统的“系统”、可编辑的 “自定义…”以及“随机”（即时生成随机调色板）。自定义调色板 存储在 QSettings 中。
终端文字颜色 单独为每个输出类别重新着色，或重置为当前主题。16 种命名 颜色。已被其他类别使用的颜色被禁用，以避免冲突。
语言 在运行时切换界面语言。英语、俄语、白俄罗斯语、德语、 法语、中文、日语、韩语。
界面缩放 75% / 100% / 125% / 150%。缩放字体、内边距、控件尺寸和 最小窗口大小。选择会被记住。
配置宏 编辑每个标签页的 10 个宏槽位。
重置所有宏 清除一个标签页或所有标签页的宏。
配置触发器 编辑每个标签页的触发器列表。
重置触发器 清除一个标签页或所有标签页的触发器。
传输设置 文件传输的块大小 / 块延迟 / 最大文件大小，以及 “记住最后发送的文件路径”。
保存格式 纯文本（.xyrm）或彩色 HTML （.xyrmc）。

11. 视图菜单

  • 显示或隐藏当前标签页上的单个分组（连接、串口设置、终端设置、 服务器、Ping）。
  • 全部显示 — 显示当前标签页的所有分组。
  • 全部隐藏 — 隐藏当前标签页的所有分组。

12. 键盘快捷键

  • Ctrl+F — 在终端中搜索。
  • F3 / Shift+F3 — 下一个 / 上一个匹配项。
  • Enter 在发送输入框中 — 发送。
  • ↑ / ↓ 在发送 输入框中 — 命令历史。
  • Esc — 关闭搜索面板。

13. 会记住什么

退出时，应用会存储窗口几何、活动标签页、COM 设置、TCP / UDP 设置、 ping 设置、终端和发送开关、分组可见性、主题（包括自定义调色板）、 界面缩放、语言、终端颜色、保存格式、所有宏和所有触发器，以及启用 “记住最后发送的文件路径”时的最后发送文件路径。下次启动时全部恢复。

14. 主题概览

  • 系统 — 跟随操作系统颜色方案（深色 → Black，浅色 → White）。
  • Purple、Gray、White、Black、Beige — 单色调色板。强调色（标签页、按钮、分组标题、高亮）使用主题色； 背景是其深色调。红色和绿色的语义按钮在任何主题下都保持红色 和绿色。
  • Turquoise-Orange、Graphite-Sand、Purple-Gold、 Coral-Mint、Navy-Crimson — 双色调色板。背景使用 第一种颜色；强调色使用第二种。
  • 自定义… — 用户定义的调色板。通过颜色选择器编辑 20 个 颜色角色中的每一个。按钮：
    • Random — 生成和谐的随机调色板。
    • Reset to defaults — 返回内置的紫色。
  • 随机（在菜单中）— 立即生成并应用随机自定义调色板。
